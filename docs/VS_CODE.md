# CF Enhance · 测试与提交

## 使用

安装 Release 中的 cf-enhance-companion-0.7.0.vsix，重新加载 VS Code，点左侧 CF Enhance 图标。

打开可信工作区和代码文件即可本地测试，无需 CPH 或浏览器连接。C++ 需要支持 C++23 的 g++，C 需要 gcc，Python 需要本机解释器；齿轮按钮可设置程序路径和时限。

顶部选择代码、题目和语言，**运行 / 提交**位于同一栏。测试期间仍可提交。默认使用当前编辑器，支持选区和另外选择文件，包含未保存的代码，不覆盖源文件。

## 用例

- ＋添加用例；输入与答案并排编辑。答案留空时仅运行并显示输出，有内容时自动比较，没有校验开关。
- 每个用例标题栏可直接运行、删除、复制输出、单独折叠。收起后仍能运行或删除，折叠状态会记住。工具栏可统一展开或折叠。
- 点击运行执行启用的用例；运行时出现停止按钮。标题显示状态和耗时，下方直接显示程序输出，诊断可从日志按钮查看。
- 用例按代码文件＋题目保存在工作区；上方切题后，样例和当前反馈立即同步切换。切回原题可恢复自定义输入。建议先保存到固定文件，再长期维护用例。修改用例会隐藏旧结果，修改代码会标记旧结果。
- 默认按空白分隔后的内容比较，数字 1 与 1.0 不视为相同。设置支持保留内部空白的 exact 比较。

普通程序输出放在独立边框内，不增加输出标题。Ctrl+Enter 运行当前用例，Ctrl+Shift+Enter 运行全部。新增用例直接聚焦输入框，误删可撤销。

## 网页样例与提交

点击右上角连接状态展开配对设置，复制配对码，在 Chrome 扩展弹窗的 VS Code 联动中连接。保持 CF 页面打开。Chrome 建议更新到本次 3.5.0。

默认跟随 Chrome 当前题，手动选题后固定；选题框旁的 ⇄ / ⌖ 可切换跟随或固定。切题自动读取各自缓存，没有样例时通过已连接的 Chrome 在后台获取，不打开新题页、不提交代码。向下箭头强制重新获取；失败会提示原因。需要 Chrome 3.5.0 并刷新至少一个 CF 页面。编辑过或删除过的样例不会被自动覆盖或复活。

顶部可独立选择网页当前题、训练场次题或手动输入题号 / 链接，选语言后点提交。Chrome 后台填写并点击 CF 原生 Submit，明确绑定编号后返回反馈。网页手动提交的本人记录也会同步。面板仅显示所选题目的最近结果；其他记录在折叠的提交历史中。失败时可点击重试提交，使用当前选择的代码，不会自动重复发送。

登录、验证码或表单问题需要处理时会提示。断线补发反馈，重启只恢复反馈，不重新发送代码。

## 手动交互测试

点击用例工具栏 ⇆ 打开独立交互窗口，点击开始运行当前代码快照。你扮演交互器：看到程序询问后输入回复，Ctrl+Enter 发送；支持追加换行、EOF、停止、重启和复制通信记录。关闭窗口会停止该窗口拥有的程序。

支持 C/C++/Python，不连接浏览器也可用。C++ 需要 endl / flush，C 需要 fflush 刷新输出；Python 使用 -u。默认会话总时限 120 秒，cfEnhance.interactiveTimeout 可调整到 1–600 秒。通信记录上限 1 MiB，不提供官方交互器或自动 AC 判定。

## 速度

连续运行未改动的 C/C++ 代码会复用上一份编译结果；修改代码、依赖头文件或编译器配置后重新编译。当前扩展窗口只保留一个编译缓存，关闭时清理。编译依赖无法确认时不会复用。

输入编辑合并后保存，点击运行前立即发送；选择题目、用例和输出使用已有节点更新，避免反复重建。小程序本机自动测试记录首次约 288ms，再次约 41ms，实际耗时随代码与设备变化。

## 设置与范围

- cfEnhance.compiler / cCompiler / python：程序名或完整路径，不含参数，默认 g++ / gcc / python。
- cfEnhance.testTimeout：单例默认 3000ms，范围 100–30000ms；编译上限 30 秒。
- cfEnhance.outputComparison：tokens 或 exact。

每文件最多 50 个用例，单项输入 / 答案最多 64 KiB，总用例存储 12 MiB。单进程输出最多 1 MiB；面板预览前 16000 字符，完整输出在日志中。

本地程序以普通子进程运行，不隔离文件系统或内存。临时构建不覆盖源文件，源码不写入用例或提交历史。编译诊断可能包含报错行。本地 AC 只代表通过所选用例。

## 验证

83 项自动检查通过，包括真实编译与头文件缓存失效、未保存快照、停止进程、离线用例、输入合并、折叠删除、提交并行、网页早期翻译及原有反馈链路。新增真实 C++ 双向交互、EOF、停止、重启、输出限制和切题关联检查。Chrome 检查紧凑面板与交互窗口渲染预览；未在 VS Code 扩展宿主里验收，也未替用户向 CF 提交。
