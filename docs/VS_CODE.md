# CF Enhance Companion

CF Enhance 的可选 VS Code 插件。浏览器插件仍然可以独立使用；安装本插件后，可以自由选择代码、目标题目和语言，在 VS Code 查看提交反馈。

## 安装与首次连接

1. VS Code 的扩展菜单选择 **Install from VSIX / 从 VSIX 安装**，选择发布包中的 `cf-enhance-companion-0.2.0.vsix`。
2. Chrome 更新 CF Enhance 到 3.0，并刷新已经打开的 CF 页面。
3. VS Code 打开可信工作区，点击左侧活动栏的 **CF Enhance 图标**，在提交面板点击 **复制配对码**。配对码有效期 5 分钟。
4. 点击 Chrome 工具栏中的 CF Enhance 图标，展开 **VS Code 联动**，粘贴配对码并点击连接。允许扩展访问本机服务；如果 Chrome 另行询问本机访问许可，也需要手动允许。
5. 保持 Chrome 有一个 CF 页面打开。面板显示“已连接”后即可使用。编辑器右上角及底部 CF Enhance 状态栏也能打开面板。

## 自由提交

在提交面板直接选择，无需反复打开命令面板：

- 当前编辑器全文、选中部分或其他文件。支持未保存的编辑器，不要求文件名对应题号。
- 网页当前题、已同步训练场次中的任意题，或输入 CF 题号 / HTTPS 链接。
- 提交语言，或在网页手动选择。

语言根据代码文件类型自动预选；尚未手动选择目标时自动跟随网页当前题。点击“选择其他文件”会自动切换代码来源；面板显示文件名、字符数和未保存标记，切到侧栏不会丢失刚才的编辑器或选区。

点击 **准备提交** 后使用当时的代码快照，之后编辑文件不会改变该任务。Chrome 会打开对应题目的原生提交页，填写代码并提示检查；**最终 Submit 由你手动点击**。不会覆盖提交页已有的其他草稿；如果已有不同内容，请自行保存并清空后点重试。

第一次连接时，如果 VS Code 的网页当前题 / 场次列表尚未更新，请在 Chrome 切回题目页，等几秒后再发起任务。

## 判题反馈

每次任务独立记录来源、题号、语言、代码摘要和 CF 提交编号。账号、题号、时间范围及代码快照能唯一对应时自动关联；源码不可见、多个相同目标提交或接口不可用时，需要在 CF 的 my/status 结果页，在**刚提交的那一行**点击“关联 VS Code”。关联后按明确的提交编号跟踪结果，不根据当前文件名猜测。

面板底部的最近提交直接显示进度、AC / WA / TLE、提交编号、耗时与内存，可点击查看网页或停止跟踪；活动栏另有可折叠的完整记录。任务完成也会弹出提示，底部状态栏显示连接状态。公开 API 和 CF 原生结果行互为补充；正式比赛期间的可见性由 CF 决定，暂时不可见时保持等待。

关闭 Chrome、扩展失效或服务断开不会自动再次提交代码。重启 VS Code 后保留任务元数据，未完成任务标为“需要重新准备”；不保存待提交源码。取消任务仅停止跟踪，不会撤回已经发送给 CF 的提交。

## 本地样例测试

Chrome 打开题目页后，在面板点击 **运行网页当前题样例（C++）**，使用面板选定的代码快照，在临时目录编译运行。默认编译器为 `g++`，可在 `cfEnhance.compiler` 设置完整程序路径；需支持 C++23。每个样例限时 3 秒，输出限 1 MiB，不提供进程内存沙箱。结果直接显示在提交面板，可展开实际输出与期望输出；完整日志在 CF Enhance 输出面板。这一步需要信任工作区，并由你点击按钮运行。

## 连接与隐私

- 本地 HTTP 服务仅监听 `127.0.0.1`，由系统自动分配空闲端口（`cfEnhance.port` 默认为 0），不经过云端。记住当前工作区端口，重启优先复用；端口被占用时自动换一个，多个窗口不再争抢固定端口。端口变化后需重新配对；面板“连接详情”可查看端口。旧版默认 27121 自动迁移到自动模式。
- 配对码一次有效，配对后用长随机凭据和 Chrome 扩展 ID 校验。VS Code 凭据存放在 SecretStorage；源码不写入提交历史或日志。
- VS Code 代码只在你创建提交任务后传给浏览器，并填写到 CF 原生提交页。Chrome 使用正常登录会话读取自己的提交源码进行核对，不读取 Cookie 的值或索取 CF API 密钥。
- Chrome 页面前台约每 4 秒唤起连接；后台由扩展 alarm 约每 30 秒检查，实际间隔受 Chrome 调度影响。CF API 继续共用 2.2 秒请求队列。
- 面板“连接详情”内点 **撤销配对** 可撤销连接；Chrome 弹窗也可断开本端。

当前为联动预览版。本地通信、可视面板交互、端口冲突恢复、命令兼容、表单适配及模拟反馈有自动化测试；没有替用户在 CF 实际提交代码，也没有通过 VS Code/Chrome 真机安装验收。网页变更、验证码或登录状态可能要求手动处理。

旧命令仍保留，习惯键盘的用户可以继续使用。Chrome 3.0.0 可直接配合本次 Companion 0.2.0；首次升级建议重新配对一次。
