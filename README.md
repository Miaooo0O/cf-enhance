# CF Enhance · Codeforces 增强

直接融入 Codeforces 原网页的 Chrome 扩展。原 CF Random 的升级版本，无需构建或 API Key。

## 安装或更新

1. 下载 Release 中的 `cf-enhance-3.0.0.zip`，解压到固定目录。
2. Chrome 打开 `chrome://extensions/`，开启开发者模式，加载包含 `manifest.json` 的文件夹。
3. 已安装用户将文件覆盖到原目录，点击扩展的重新加载，再刷新 CF 页面。沿用原目录和 Chrome 配置可保留历史记录。

若更新后旧 CF 页面出现 `Extension context invalidated`，请刷新这些 CF 页面。2.1.1 起会捕获连接失效、停止旧页面的定时检查，并提示刷新；它不会自动刷新或清除编辑中的代码。Chrome 扩展管理页中已经产生的旧错误日志可手动清除。

本扩展尚未上架 Chrome 应用商店。运行无需安装 Node.js 或 npm。

## 网页入口与显示

- 顶部导航 **Help → 题单 → 中文**。题单入口前往独立的场次列表页面。每场训练有自己的独立地址。
- 题库、题目页等页面的原生子导航下有随机跳题、刷题记录、显示设置，以及标签、分数的快捷开关。
- 文字链接、细灰边框、蓝色标题和斑马纹表格沿用 CF 的视觉风格，没有悬浮品牌按钮。
- **中文**只翻译常用导航、按钮和表单标签，支持随时切回原文；题目名称、题面、样例、代码和用户名不翻译。标签选择器提供中文名称与英文原名；CF 原页面的常用标签也支持中文显示。覆盖固定常用词条，不是全站机器翻译。浏览器自带的文件选择器仍由系统语言控制。
- 标签和分数独立隐藏，覆盖题目页侧栏及 problemset 列表；支持收起侧栏和放大题面行距。已有原生样例复制按钮时不重复添加。
- 所有显示偏好保存在本机并同步到已打开的 CF 标签页。

## 抽题与刷题记录

1. 打开随机跳题，填写 CF handle 并点击同步记录。通过公共 `user.status` 分页获取全部提交，全部成功后才替换账号记录；失败时保留之前的完整数据。
2. 选择排除已 AC、排除所有尝试过的题，或不排除。没有完整账号记录时不会假装完成排除，可选择不排除继续使用。
3. 设置评分区间、英文标签（可用中文关键词搜索）、全部/任一标签，以及是否避免重复抽取。只抽有评分的普通题库题目，不覆盖整个 Gym。
4. 随机题目在后台新标签打开；点击结果链接可前往。
5. 刷题记录可按题号/题名、状态、评分、标签和抽题日期筛选。旧版记录会保留，但缺失的时间与重复次数无法还原。

“重置去重记录”只清空抽题排除集合，保留可查看的日志。记录、设置和所有训练场次均保存在当前 Chrome 配置中。

提交记录完整同步超过一天后，启用账号排除时需要先重新同步。练习页前台每 30 秒检查最近提交，切到后台会停止请求；多个页面共用短期缓存和 API 队列。近期检查可补充新的 AC，全量同步才能可靠处理较老提交的重新评测。

## AC 提示与提交辅助

- 已同步账号通过当前题目后，题目上方显示绿色 AC 卡片和“再跳一题”。沿用抽题条件，并排除当前这道题；不会自动切走页面。
- 从 problemset 题目页点击 Submit，会转到对应 contest 的提交表单，携带明确题号及练习标记；保留原有代码和语言，不自动提交。
- 对由上述练习入口发起的提交，先记录提交基线，再在对应比赛的 my/status 页面匹配账号、题号、提交 ID、时间及 OK 结果后显示本次 AC 提示。题目页侧栏快速提交也会尝试跟踪。
- 本次提示依赖公共 API 可见性、提交前取得基线，以及与同步 handle 一致的登录账号。快速提交过早、接口不可用、账号不同或复杂页面跳转时，可能无法显示本次提示；仍可回题目页手动检查/同步。
- 实际提交后的完整流程仍待用户实测；开发验证不会替用户提交代码。

## 独立训练场次（2.1）

点击 Help 后的“题单”，进入独立页面 `https://codeforces.com/problemset?cfe=training`。这里沿用 CF 页头和样式，内容由本扩展渲染；没有安装扩展时，此地址只会显示 CF 普通题库。

- **场次列表**：保存所有场次，显示题数、已看数、AC 数和创建时间。2.0 的旧题单会自动迁移进来；创建新场次不会替换旧场次。
- **创建场次**：每行设置评分、题数、标签与匹配模式，支持中文或英文标签输入。最多 12 组、总计 50 题。可在本页面选择排除 AC、尝试记录和以往抽题。
- **场次页面**：每场有独立地址与名称，列出 A、B、C…及题目名称、分数、标签、是否看过、做题状态和最近结果；可搜索题目，筛选未看、已看、未提交、尝试中和 AC。
- **自由选题**：点击任意一题进入 CF 原生题目页；保留原始题面、公式、样例和提交功能。右侧“本场训练”列出全部题目，可随意切题或返回本场；AC 卡片会提供返回本场选题入口。
- **看题记录**：从本场链接进入题目页后才记为本场“已看”。看题记录按场次隔离，不读取浏览历史；同一题出现在两场时，各场的看题状态互不影响。
- **做题记录**：跟随填写并同步的 CF handle，AC、尝试状态来自公开提交；没有同步时标为未知。它与本机“看过”记录是两套状态。

同场题目不重复；条件重叠时通过匹配分配，避免宽条件抢占窄条件唯一候选。题目不足时不修改已有场次。

场次只保存在当前浏览器，不是 CF 官方比赛，不提供官方排名或比赛计时。其他电脑或未安装扩展的浏览器不能直接访问本机场次。实际提交后的完整跳转链路仍需用户实测。

## VS Code 可选联动（Companion 0.2.0）

浏览器插件仍可独立使用。安装 Release 中的 `cf-enhance-companion-0.2.0.vsix` 后，可以自由选择当前编辑器、选中部分或其他文件，再独立选择目标题目和语言，建立本次提交快照。在 CF 原生提交页检查并点击 Submit，VS Code 任务侧栏接收判题反馈。

首次使用：点击 VS Code 左侧 **CF Enhance 图标**，在可视提交面板点 **复制配对码**，再在 Chrome 工具栏插件弹窗中展开 **VS Code 联动**，粘贴配对码并连接。需要允许访问本机服务，保持一个 CF 页面打开。完整操作见 [VS Code 插件说明](docs/VS_CODE.md)，协议见 [联动实现](docs/INTEGRATION.md)。

支持网页当前题、手动题号 / 链接与训练场次选题，不要求固定文件名或目录。任务与提交编号绑定，不受之后编辑文件或切换题目影响。无法自动确认时，在 CF 结果页的本次提交行点“关联 VS Code”。面板会自动识别当前代码和网页题目、按文件类型预选语言；可直接切换文件、选区或目标题目，查看提交进度、耗时与内存。提供 C++ 样例测试按钮，需要本机 g++。本机端口由系统自动分配，端口冲突自动更换。

本版不会自动点击 Submit，不会解决验证码，没有启用正式比赛倒计时自动切题。

## 权限与隐私

基础功能使用 storage、alarms 和 CF 域名权限。本机 http://127.0.0.1/* 为可选权限，仅在用户点击连接时请求。未配对时浏览器不访问本机服务。

日常题库与账号同步请求公共 API。用户创建联动任务后，选定的代码快照经配对连接传给浏览器并填写到 CF；提交后可使用正常 CF 登录会话读取自己的提交源码核对摘要，不读取 Cookie 的值或索取密码 / API Key。源码不写入 VS Code 历史或日志，完成和取消后释放待提交源码。

任务元数据保存在本机，配对凭据存入 VS Code SecretStorage 与 Chrome 扩展存储。不读取浏览历史，不上传遥测，不使用云端中转。

CF API 仍共用 2.2 秒队列，本机服务仅监听 127.0.0.1。Chrome 前台约 4 秒检查，后台 alarm 约 30 秒，实际间隔受 Chrome 调度影响；断线不自动重新提交。
