# CF Enhance · 测试与提交

## 使用

安装 Release 中的 cf-enhance-companion-0.6.0.vsix，重新加载 VS Code，点左侧 CF Enhance 图标。

打开可信工作区和代码文件即可本地测试，无需 CPH 或浏览器连接。C++ 需要支持 C++23 的 g++，C 需要 gcc，Python 需要本机解释器；齿轮按钮可设置程序路径和时限。

顶部选择代码、题目和语言，**运行 / 提交**位于同一栏。测试期间仍可提交。默认使用当前编辑器，支持选区和另外选择文件，包含未保存的代码，不覆盖源文件。

## 用例

- ＋添加用例；输入与答案并排编辑。答案留空时仅运行并显示输出，有内容时自动比较，没有校验开关。
- 每个用例标题栏可直接运行、删除、单独折叠。收起后仍能运行或删除，折叠状态会记住。工具栏可统一展开或折叠。
- 点击运行执行启用的用例；运行时出现停止按钮。标题显示状态和耗时，下方直接显示程序输出，诊断可从日志按钮查看。
- 用例按代码文件保存在工作区。建议先保存到固定文件，再长期维护用例。修改用例会隐藏旧结果，修改代码会标记旧结果。
- 默认按空白分隔后的内容比较，数字 1 与 1.0 不视为相同。设置支持保留内部空白的 exact 比较。

## 网页样例与提交

点击右上角连接状态展开配对设置，复制配对码，在 Chrome 扩展弹窗的 VS Code 联动中连接。保持 CF 页面打开。Chrome 建议更新到本次 3.4.0。

打开目标题目后点击向下箭头同步样例。相同样例去重，手写和修改过的样例保留；切换题目只替换未编辑的旧网页样例。

顶部可独立选择网页当前题、训练场次题或手动输入题号 / 链接，选语言后点提交。Chrome 后台填写并点击 CF 原生 Submit，明确绑定编号后返回反馈。网页手动提交的本人记录也会同步。面板显示最近一条，更多历史可从提交任务列表查看。

登录、验证码或表单问题需要处理时会提示。断线补发反馈，重启只恢复反馈，不重新发送代码。

## 速度

连续运行未改动的 C/C++ 代码会复用上一份编译结果；修改代码、依赖头文件或编译器配置后重新编译。当前扩展窗口只保留一个编译缓存，关闭时清理。编译依赖无法确认时不会复用。

输入编辑合并后保存，点击运行前立即发送；选择题目、用例和输出使用已有节点更新，避免反复重建。小程序本机自动测试记录首次约 288ms，再次约 41ms，实际耗时随代码与设备变化。

## 设置与范围

- cfEnhance.compiler / cCompiler / python：程序名或完整路径，不含参数，默认 g++ / gcc / python。
- cfEnhance.testTimeout：单例默认 3000ms，范围 100–30000ms；编译上限 30 秒。
- cfEnhance.outputComparison：tokens 或 exact。

每文件最多 50 个用例，单项输入 / 答案最多 64 KiB，总用例存储 12 MiB。单进程输出最多 1 MiB；面板预览前 16000 字符，完整输出在日志中。

本地程序以普通子进程运行，不隔离文件系统或内存。临时构建不覆盖源文件，源码不写入用例或提交历史。编译诊断可能包含报错行。本地 AC 只代表通过所选用例。

## 验证

76 项自动检查通过，包括真实编译与头文件缓存失效、未保存快照、停止进程、离线用例、输入合并、折叠删除、提交并行、网页早期翻译及原有反馈链路。Chrome 实际渲染预览检查 240 / 320 / 440px；未在 VS Code 扩展宿主里验收，也未替用户向 CF 提交。

界面操作参考 [CPH 用例组件](https://github.com/agrawal-d/cph/blob/main/src/webview/frontend/CaseView.tsx)，实现独立维护。
