# CF Enhance · 本地评测与提交

精简的 VS Code 本地评测工具，日常测试无需 CPH，也无需连接网页。本地支持 C++、C 和 Python；连接 Chrome 后还可同步 CF 样例、直接提交并接收反馈。

## 安装

1. 在 VS Code 扩展菜单选择“从 VSIX 安装”，安装 cf-enhance-companion-0.5.0.vsix，重新加载窗口。
2. 点击左侧 CF Enhance 图标，默认打开“测试”页。编辑器右上角和底部状态栏也可打开。
3. 打开可信工作区和代码文件即可测试。C++ 需要 g++（支持 C++23），C 需要 gcc，Python 需要本机解释器；面板“设置”可修改程序路径和时限。

无需卸载或启用 CPH，本插件不改动原 CPH 用例。旧版“导入 CPH”入口已由独立的本地测试页替代。

## 自定义用例

- 直接编辑输入，点击“＋”添加用例。
- 勾选“校验期望输出”并填写结果。不勾选时只显示实际输出，不判断通过或失败；勾选后期望输出可以为空。
- 点击“运行全部”测试启用的用例，也可展开某个用例点“运行”。“停止”可中止编译或运行。
- 结果显示实际输出、期望输出、错误输出与耗时。默认按空白分隔后的内容比较，可在设置切换为保留内部空白的比较。
- 用例按代码文件关联，保存在当前工作区。切换文件或重新加载窗口后仍可读取；建议保存代码到固定文件，再长期维护用例。

运行使用当前编辑器、选区或选定文件的代码快照，包含未保存的修改，不覆盖源文件。修改用例后旧结果会隐藏；修改代码后会标记旧结果。

## 同步网页样例

点击顶部“本地模式 / 网页已连接”展开连接设置，复制配对码，到 Chrome 插件弹窗的“VS Code 联动”粘贴连接。

Chrome 打开目标题目，等题号同步后点“同步样例 · 题号”。无需 CPH，不要求代码文件名等于题号。已有 Chrome 3.2.0 即可配合本地评测；本次附带 Chrome 3.3.0 还增加了题单删除。

同题重复同步会去重。切换题目后，只替换未改动的旧网页样例，保留手写用例；修改过的网页样例也按手写用例保留。如果“提交”页选择了另一题，需先在 Chrome 打开对应题目。

## 提交与反馈

切换到“提交”页，独立选择当前网页题、训练场次题目或输入题号 / 链接，选语言后点提交。Chrome 在后台准备并点击 CF 原生 Submit，按明确编号返回结果；网页手动提交的本人记录也进入反馈。

原提交标签页的唯一新结果可以直接绑定，公共 API 卡住不会阻塞网页反馈。无法唯一确认时保留结果行手动关联。断线后补发反馈，重启只恢复反馈，不重新发送代码。登录、验证码或表单问题会提示处理。

## 设置与范围

- cfEnhance.compiler：C++ 编译器，默认 g++，使用 C++23。
- cfEnhance.cCompiler：C 编译器，默认 gcc，使用 C17。
- cfEnhance.python：Python 解释器，默认 python。填写程序名或完整程序路径，不含参数。
- cfEnhance.testTimeout：单例时限，默认 3000 毫秒，范围 100–30000；编译限时 30 秒。
- cfEnhance.outputComparison：tokens（默认）或 exact（保留内部空白，忽略换行格式与末尾空白）。

每文件最多 50 个用例，输入或期望输出最多 64 KiB，用例总存储限 12 MiB。每次进程输出最多 1 MiB；面板预览较长结果的前 16000 字符，完整诊断可在“完整输出”查看。

本地测试是普通子进程，不隔离内存和文件系统。编译器诊断可能包含出错行，完整源码不会写入用例存储或提交历史。本地通过不代表 CF 判题 AC。

## 验证

72 项自动检查通过，包括真实 C++ 编译运行、离线评测、未保存快照、自定义输入输出、停止进程、用例重载、样例去重、编辑保护、题单删除恢复与原有提交反馈。未通过用户的 VS Code 安装界面验收，也没有代用户向 CF 提交代码。
